ЗАДАЧА: РАЗРАБОТКА ГРАФОВОЙ БАЗЫ ДАННЫХ ДЛЯ АРТ-ГАЛЕРЕИ

Необходимо спроектировать и реализовать графовую базу данных на платформе MS SQL Server для моделирования взаимодействия художников, их картин и выставок в арт-галерее.

СУЩНОСТИ (УЗЛЫ / NODES):

1. Artist (художник) — содержит:
   - ArtistID (INT, PK) — идентификатор художника
   - Name (NVARCHAR(50)) — имя художника
   - Country (NVARCHAR(30)) — страна происхождения
   
   Примеры экземпляров: Винсент Ван Гог (Нидерланды), Иван Айвазовский (Россия), Пабло Пикассо (Испания).

2. Painting (картина) — содержит:
   - PaintingID (INT, PK) — идентификатор картины
   - Name (NVARCHAR(50)) — название картины
   - Year (DATE) — год создания
   - Style (NVARCHAR(30)) — художественный стиль
   
   Примеры экземпляров: "Звездная ночь" (1889, Постимпрессионизм), "Девятый вал" (1850, Романтизм), "Герника" (1937, Кубизм).

3. Exhibition (выставка) — содержит:
   - ExhibitionID (INT, PK) — идентификатор выставки
   - Name (NVARCHAR(100)) — название выставки
   - City (NVARCHAR(50)) — город проведения
   - Date (DATE) — дата открытия
   
   Примеры экземпляров: "Постимпрессионизм: Ван Гог и современники" (Париж), "Маринисты: искусство моря" (Санкт-Петербург).

СВЯЗИ (РЁБРА / EDGES):

1. CreatedBy (создал) — направленная связь от Artist к Painting.
   Атрибут ребра: Commission (MONEY) — гонорар художника за создание картины.
   Ограничение: связывает только Artist и Painting.

2. OwnedBy (экспонируется на) — направленная связь от Painting к Exhibition.
   Атрибут ребра: InsuranceValue (MONEY) — страховая стоимость картины.
   Ограничение: связывает только Painting и Exhibition.

3. OrganizedBy (организовал) — направленная связь от Artist к Exhibition.
   Атрибут ребра: Fee (MONEY) — гонорар художника за организацию выставки.
   Ограничение: связывает только Artist и Exhibition.

ЗАПОЛНЕНИЕ ДАННЫМИ:

- Таблица Artist: 3 записи (3 художника)
- Таблица Painting: 17 записей (7 картин Ван Гога, 5 картин Айвазовского, 5 картин Пикассо)
- Таблица Exhibition: 5 записей (3 тематические выставки, 2 сборные)
- Таблица CreatedBy: 17 записей (каждая картина связана со своим художником)
- Таблица OwnedBy: 20 записей (картины участвуют в 1-2 выставках)
- Таблица OrganizedBy: 8 записей (художники организуют выставки)

ЦЕЛИ РАБОТЫ:

1. Реализовать графовую базу данных с использованием синтаксиса AS NODE и AS EDGE в MS SQL Server.
2. Написать 5 различных запросов с использованием функции MATCH для анализа цепочек:
   - Художник → Картина → Выставка ← Другой художник
   - Художник → Картина → Выставка ← Этот же художник
   - Полная информация о пути: Художник → Картина → Выставка
   - Фильтрация по стилям картин (Кубизм, Романтизм)
   - Агрегация: картины, участвующие в нескольких выставках
3. Написать 2 запроса с использованием SHORTEST_PATH:
   - Шаблон "+" — путь от Ван Гога до всех выставок
   - Шаблон "{1,3}" — путь от Пикассо до выставок за 1-3 шага
4. Визуализировать полученный граф в Power BI с помощью Force-Directed Graph (3 страницы: CreatedBy, OwnedBy, OrganizedBy).
5. Создать диаграммы в diagrams.net (3 страницы: Artist, Painting, Exhibition).
